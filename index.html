Tetapan SisPAQ

1Maklumat Rasmi Institusi

2Kawalan Tingkatan

Tambah dan hapus tingkatan hanya boleh dibuat oleh admin melalui paparan ini.

3Tetapan Tandatangan Cetakan

Nama di sini akan digunakan secara automatik pada paparan cetak senarai mengikut tingkatan.

4Pengurusan Pengesahan

5Sandaran JSON

Eksport atau import fail sandaran pangkalan data dalam format JSON.

6Kelulusan Akaun Guru

Tekan Luluskan untuk mengaktifkan akaun guru. Gunakan Hapus Akaun jika guru tidak lagi menggunakan sistem.

7Hapus Semua Rekod Prestasi Pelajar

Tindakan ini hanya akan menghapus semua rekod prestasi pelajar.

Kegunaan SisPAQ

  1. Log masuk menggunakan alamat e-mel dan kata laluan yang telah didaftarkan. Akaun guru baharu perlu mendapat kelulusan pentadbir sebelum boleh digunakan.
  2. Semak ringkasan prestasi pada halaman Utama.
  3. Buka Borang Prestasi, pilih tingkatan, lengkapkan maklumat laporan dan tekan Simpan.
  4. Buka Prestasi Hafazan dan pilih tingkatan untuk melihat rekod pelajar.
  5. Tekan Tambah Rekod (Pelajar Baharu), kemudian masukkan nama pelajar, kategori sukatan, muka surat semasa, peratus bulanan dan nama guru.

Soalan Lazim

  • Bagaimanakah cara mengemas kini rekod pelajar lama?
    Tekan ikon Kemas Kini pada baris nama pelajar.
